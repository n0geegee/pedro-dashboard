> **For Hermes:** Execute this plan task-by-task against the live Pedro Dashboard tree. Preserve unrelated dirty worktree changes.

**Goal:** Add a small, allowlisted vanilla-JS slot runtime so UL/UR/LL/LR can be replaced by changing a versioned assignment, while preserving the existing 1920×1200 shell and current kiosk behavior.

### Task 2: Add explicit slot assignment configuration

**Create:** `app/static/slot-layout.json`.

Use schema version 1 and engine `slots-v1` with this baseline:

```json
{
  "schema_version": 1,
  "engine": "slots-v1",
  "revision": "baseline-birdwatch-1",
  "slots": {
    "UL": { "module": "volleyball", "enabled": true },
    "UR": { "module": "polsat-status", "enabled": true },
    "LL": { "module": "birdwatch", "enabled": true },
    "LR": { "module": "photos", "enabled": true }
```

The file is static, allowlisted configuration only. It contains no executable paths or arbitrary imports.

### Task 3: Implement and test the generic runtime seam

**Create:** `app/static/slot-runtime.js`.

Implement a browser/CommonJS-compatible `PedroSlotRuntime` API:

- `SLOT_IDS = ["UL", "UR", "LL", "LR"]`;
- `validateLayout(layout, registry)` validates schema/engine, exact slot IDs, known modules, and `supportedSlots`;
- `create(options)` owns per-slot mounted records, generation counters, `AbortController` cancellation, `isCurrent()` stale-callback guard, `mount/update/unmount` ordering, local error isolation, and `setLayout()` for a future assignment swap;
- runtime resolves only hosts supplied by the shell and never queries another slot;
- disabled/invalid assignments resolve to an explicit local fallback rather than stopping sibling slots;
- no dynamic imports and no global DOM mutation outside the supplied host.

**Test:** `tests/test_slot_runtime.js` using Node built-ins and deterministic fake hosts/modules.

Cover:

- valid baseline layout;
- unknown module/unsupported slot/bad schema rejection;
- `mount()` once, repeated `update()`, and one `unmount()` per generation;
- changing LL assignment unmounts Birdwatch before mounting the replacement;
- stale old-generation callback sees `isCurrent() === false`;
- one throwing module does not stop sibling slots;
- disabled slot uses the explicit fallback.

### Task 4: Wire the runtime into the existing frontend without visual redesign

**Modify:**

- `app/static/index.html` — add `data-slot="UL|UR|LL|LR"` to the four existing center/right card hosts and load `/static/slot-runtime.js` before `/static/app.js`.
- `app/static/app.js` — add:
  - static layout URL plus a matching in-code fallback;
  - registry wrappers for `volleyball`, `polsat-status`, `birdwatch`, and `photos` around the existing render functions;
  - fixed shell-owned host resolution for the preserved card body nodes;
  - one-time layout loading with fallback if the JSON is unavailable;

Remove the replaceable UL/LL cases from the central `renderCard()`/`pairs` dispatch. Keep the left-column cards on their existing direct dispatch. Keep `renderFullscreenSlideshow()` and `updateDisplayRotation()` outside the slot runtime.

Do not change `styles.css`, backend state contracts, probe files, or the rotation policy for this refactor.
